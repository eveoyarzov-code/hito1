# Pizzería Mamma Mía 🍕 - Hito 1

Este proyecto es la primera entrega (Hito 1) de una aplicación web para una pizzería, construida con el objetivo de practicar los conceptos básicos de **React** y el uso de componentes con **Vite**.

## ✨ Características y Componentes

- **`Navbar`**: Barra de navegación con cálculo de total simulado y botones que cambian según si el usuario inició sesión (`token`).
- **`Header`**: Banner principal con el título y eslogan de la pizzería.
- **`CardPizza`**: Componente reutilizable para mostrar las pizzas utilizando `props` (nombre, precio, ingredientes e imagen).
- **`Home`**: Contenedor principal que agrupa el catálogo de pizzas.
- **`Footer`**: Pie de página con los derechos reservados.

## 🛠️ Tecnologías

- React
- Vite.js
